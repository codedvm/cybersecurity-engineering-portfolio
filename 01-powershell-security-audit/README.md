
# Project 01: Windows Endpoint Security Audit

## Objective

Develop a PowerShell-based security auditing tool to assess Windows endpoint security configurations and identify potential security weaknesses.

## Planned Security Checks

- Microsoft Defender protection status
- Windows Firewall profile status
- Secure Boot configuration
- BitLocker encryption status
- Operating system information
- Security update status

## Expected Deliverables

1. Read-only PowerShell audit script
2. Structured CSV/JSON reporting
3. Test results from a personal Windows lab
4. Technical documentation
5. Recommendations for identified risks

## Status

Planning and development.

## Security Considerations

The script will initially perform read-only checks and will be tested on personally controlled lab systems.
